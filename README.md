# Location-Aware QR Code Attendance System for Educational Institutions

The Location-Aware QR Code Attendance System is a web-based application developed for educational institutions to simplify and secure student attendance management. The system uses QR code scanning along with real-time location verification to ensure accurate attendance tracking.

This project helps institutions reduce manual attendance processes, improve efficiency, and prevent proxy attendance.

## How It Works

1. Faculty generates a QR code for attendance.
2. Students scan the QR code using the application.
3. The system verifies the student's location.
4. Attendance is recorded in the database.
5. Faculty can view and manage attendance reports.

## Installation

### Clone the Repository

```bash
git clone https://github.com/mogilisravya/Location-Aware-QR-Code-Attendance-System-for-Educational-Institutions.git
```

### Navigate to the Project Folder

```bash
cd Location-Aware-QR-Code-Attendance-System-for-Educational-Institutions
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Server

```bash
python manage.py runserver
```
